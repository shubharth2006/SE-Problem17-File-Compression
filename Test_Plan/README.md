# Software Test Plan — Problem 17

Testing covers the Huffman-based File Compression Tool.

## Main areas
- File selection and file reading
- Frequency calculation
- Huffman tree construction
- Huffman code generation
- Compression and compressed-file creation
- Decompression and decoding
- Restoration of original data
- Compression statistics
- Error and corrupted-file handling
- Data integrity and security validation

## Test levels
Unit, integration, system, regression, performance, negative/boundary, and acceptance testing.
